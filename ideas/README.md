# Ideas

Shared idea board for the BlackWater team.

1. Make a folder with your name: `ideas/<your-name>/`.
2. Copy `TEMPLATE.md` into it for each idea.
3. Teammates add their vote at the bottom. Don't edit someone else's idea text. Reply with your vote or open an Issue.
4. Once the team agrees, the idea gets built on a `<name>/<topic>` branch and merged through a PR.
